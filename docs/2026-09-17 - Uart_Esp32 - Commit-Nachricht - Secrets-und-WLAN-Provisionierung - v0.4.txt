BL_Add secrets defaults and WiFi provisioning
Date: 2026-09-17

Summary:
- Added optional arduino_secrets.h support with safe compile-time fallback values.
- Changed configuration loading to prefer NVS, then arduino_secrets.h, then internal defaults.
- Prevented noisy Preferences NOT_FOUND messages by checking NVS keys before reading strings and float/blob values.
- Added fallback AP WiFi scanning and network selection in the web interface.
- Persisted WLAN credentials selected in the web interface to NVS for subsequent boots.
- Added a Git-safe arduino_secrets.example.h template and explicit secret-file ignore rules.
- Updated project documentation for version v0.4.
