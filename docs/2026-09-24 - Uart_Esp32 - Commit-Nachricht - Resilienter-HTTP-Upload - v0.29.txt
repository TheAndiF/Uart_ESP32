BL_Add resilient HTTP upload retries
Date: 2026-09-24

Summary:
- Added resilient Browser-to-ESP32 HTTP retry handling for UART file uploads.
- Added upload-status reconciliation after interrupted HTTP requests so an already accepted or verified block is not appended twice.
- Made upload block submission idempotent for already confirmed blocks and identical in-flight duplicate requests.
- Added HTTP retry diagnostics to the upload web page.
- Kept the v0.28 UART upload pacing unchanged: 4096-byte blocks, 512-byte UART segments, 45 ms segment pacing, 140 ms pre-verification delay and 5 s block verification timeout.
- Preserved the saved local reference path and BX3 target path across the version update.
